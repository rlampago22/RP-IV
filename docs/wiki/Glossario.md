# Glossário

| Termo | Significado |
|-------|-------------|
| EDA | Arquitetura Orientada a Eventos |
| EventBus | Barramento in-process que publica/entrega eventos |

| UC01 | Caso de uso de medição / monitoramento (fluxo principal, alt. observação, exceção falha) |
| Alarme | Notificação por violação de limiar; ciclo emitido → reconhecido → resolvido |
| Auditoria | Log append-only com encadeamento SHA-256 |
| Opção A | UI oficial SCADA escuro (React + protótipo HTML) |
