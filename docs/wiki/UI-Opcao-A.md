# UI Opção A — SCADA escuro

**Direção oficial** (decisão 16/09/2026).

## Essência

Evolução web do SCADA do MVP Swing (Marcus): sala de controle, tipografia sóbria, cor só para status/alarme.

## Chrome (todas as telas)

| Zona | Conteúdo |
|------|----------|
| Top bar | Reator-01 + badge ESTÁVEL / ATENÇÃO / CRÍTICO |
| Tabs | Visão Geral · Sensores · Alarmes · Auditoria · Demo |
| Banner | Alarme ativo + Validar/Reconhecer |
| Conteúdo | Único que muda por tela |
