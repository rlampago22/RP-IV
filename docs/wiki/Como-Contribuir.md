# Como Contribuir

## Fluxo Git

1. Atualize `desenvolvimento`
2. Trabalhe na branch pessoal (`alvaro`, `bernardo`, `bruno`, `jose`, `marcus`) ou `fix-…`
3. Abra PR → `desenvolvimento`
4. **Nunca** commit direto na `main`

## Commits

Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, `test:`, `refactor:`).

```bash
git config core.hooksPath .githooks
```

## Entrega vertical (sprints)

Cada issue de semana deve trazer:

- [ ] Backend / domínio / doc da trilha
- [ ] Pedaço React T0X no chrome **Opção A**
- [ ] Relatório em `docs/semanas/AAAA-MM-DD/<nome>.md`

Template: [`_template-entrega-vertical.md`](https://github.com/rlampago22/RP-IV/blob/desenvolvimento/docs/semanas/_template-entrega-vertical.md)

Guia completo: [`CONTRIBUTING.md`](https://github.com/rlampago22/RP-IV/blob/desenvolvimento/CONTRIBUTING.md)
